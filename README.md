# Představení knihovny Cartopy

Cartopy je open-source knihovna určená především pro kartografickou vizualizaci prostorových dat a tvoření kvalitních mapových výstupů. Původně byla vyvinuta britskou meterologickou službou UK Met Office pro rychlé a přesné zobrazení geografických dat. Cartopy je postavena na knihovně Matplotlib, jejíž možnosti rozšiřuje geografickými souřadnicemi a kartografickými zobrazeními. Zároveň využívá další knihovny pro výpočet souřadnicových transformací (PROJ), nymerické výpočty (NumPy) a práci s geometriemi (Shapely).

 Hlavní přednosti knihovny:
 * Široká nabídka kartografických zobrazení 
 * Automatická transformace souřadnic
 * Integrace s Matplotlib - umožňuje kombinovat mapy s grafy, diagramy a dalšími vizualizacemi
 * Dostupná data – podporuje Natural Earth a načítání dalších geografických vrstev

Nejedná se ovšem o samostatný analytický nástroj, nedokáže nahradit GIS software. Výstupy jsou v základu statické, pro vyšší interaktivitu je třeba využití dalších podpůrných knihoven.
